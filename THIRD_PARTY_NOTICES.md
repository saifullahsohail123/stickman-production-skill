# Scope and credits

MIT here applies to this package's original instructions, helpers and generic
demo. It does not relicense external applications, model weights, voice recordings
or a user's output artwork. Those dependencies are not bundled.

Required tools are independently installed from their upstream projects:

- [VectorCraft](https://github.com/storytold/vectorcraft)
- [Voicebox](https://github.com/jamiepine/voicebox)
- [Concat](https://github.com/jub0t/concat)

Planning inspiration includes the MIT-licensed
[Stickman Video Director](https://github.com/kaomei/stickman-video-director).
This package does not redistribute its runtime, examples, prompt library or
generated images. Its planning ideas are adapted to a different tool pipeline.

Optional Python media dependencies (`av`, `numpy`, `Pillow`) retain their own
licences. Install them independently. Review a chosen TTS model's own licence:
an open-source client does not make a hosted voice or noncommercial model an
unrestricted offline dependency. The Urdu research note records concrete examples.
